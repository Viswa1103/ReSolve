# ReSolve

ReSolve is a web application that helps users log coding problems, organize them by pattern and difficulty, schedule reviews using spaced repetition, and monitor their progress through insightful statistics.

The application includes user registration and login, allowing each user to manage their own problems and review history. The backend is built with Node.js and Express.js, while Neon PostgreSQL is used to store user and problem data.

## Tech Stack

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Neon PostgreSQL
